Buildflow: отчёты из Odoo в Telegram

Команда Студии разработала бота, через которого руководители могут в любое время быстро получить на телефоне отчёты по движению средств из Odoo: по подрядчику, проекту или корпусу.

Исходная задача

Раньше руководители собирали отчёты по текущим объектам на компьютере из множества таблиц. После перехода к ERP данные стали доступны в Odoo, но для просмотра отчёта по-прежнему требовался компьютер. Buildflow нужен был мобильный канал, через который можно быстро получить нужные данные по подрядчику, проекту или корпусу.

Сложности и ограничения

Один и тот же массив финансовых данных нужно было представить в трёх разных разрезах и сделать удобным для просмотра на телефоне. Telegram выступает интерфейсом запроса, а источником данных остаётся Odoo, поэтому бот должен формировать отчёт в контексте выбранного объекта.

Что реализовано

Команда Студии связала Telegram-бота с данными Odoo и реализовала получение подробного отчёта в выбранном разрезе:

  • По подрядчику: отчёт о движении средств в рамках выбранного контрагента.
  • По проекту: данные в контексте отдельного проекта.
  • По корпусу: более детальный срез внутри строительного проекта.

Текущий результат

В апреле 2026 года разработка бота была завершена. Руководители могут в любое время быстро получать на телефоне отчёты по текущим объектам — по подрядчику, проекту или корпусу — на основе данных Odoo.

Мобильный доступ повысил частоту сверок: отчёт больше не требует работы за компьютером. Это помогает раньше замечать несостыковки в данных.

Этот кейс посвящён отдельной задаче — отчётности через Telegram. На странице внедрения Odoo для Buildflow описаны реестры смет, договоров и актов, с которых началась работа над ERP.
